Terminal-Style Portfolio Website

A responsive, single-page terminal-inspired personal portfolio built using pure HTML and CSS.
This project presents professional information through simulated command-line interactions, creating a developer-centric, product-focused storytelling experience.

Overview

This portfolio mimics a Unix/macOS terminal interface to display:

Professional identity and role

Career summary

Skills and technical stack

Experience and key projects

Education

Contact information

The objective is to provide a memorable, technical, and recruiter-friendly alternative to traditional portfolio layouts while maintaining clarity and performance.

Features

Terminal-style UI with macOS window controls

Simulated shell commands (whoami, cat, node, tail, curl)

Syntax-highlighted outputs for readability

Sequential command animations using CSS

Fully responsive layout (desktop, tablet, mobile)

Internal scrolling for smaller screens

Pure HTML & CSS (no JavaScript, no frameworks)

Lightweight and fast loading

Tech Stack

HTML5

CSS3

Flexbox

Media queries

Keyframe animations

Google Fonts – Fira Code

Font Awesome 6

How It Works

Each section of the portfolio is displayed as a terminal command:

Command	Description
whoami	Displays name and professional role
cat profile.txt	Professional summary
node list_skills.js	Skills and competencies
tail -n experience.log	Experience and projects
curl /education	Education details
./contact_me.sh	Contact information

Animations are staggered using CSS delays to simulate real command execution.

Responsive Design

Desktop: Centered terminal window with full animation flow

Mobile:

Optimized font sizes

Reduced padding and indentation

Safe word wrapping for long text, emails, and URLs

Vertical scrolling enabled inside the terminal window

Customization

To personalize this portfolio:

Update text content inside index.html

Modify name, role, skills, experience, and contact details

Adjust color variables or font sizes in the CSS section

Change the window title and prompt username if required

No build tools or refactoring needed.
